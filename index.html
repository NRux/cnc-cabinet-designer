Файлы для SketchUp и производства

SketchUp открывает модель через «Файл → Импорт → COLLADA (.dae)». Формат .skp закрытый, поэтому модель передаётся в .dae и .obj без потерь размеров. Для ЧПУ и раскроя — DXF в миллиметрах.

ZIP · DAE · OBJ · DXF · CSV

Полный пакет

  • model.dae — для SketchUp
  • model.obj + .mtl — для 3ds Max, Blender, Rhino
  • details.dxf — контуры деталей
  • nesting.dxf — карта раскроя листов
  • cutlist.csv — спецификация
  • project.json — проект
